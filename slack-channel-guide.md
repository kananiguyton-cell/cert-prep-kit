# #cert-prep — Channel Guide

The channel is the source of truth for our cert prep pipeline. Post naturally —
an AI parses the channel weekly, so exact formatting isn't required — but these
templates make parsing reliable and keep posts scannable for humans too.

## The three post types

**1. Exam result** (post the day you sit an exam, pass or fail)
```
📋 RESULT: Tableau Next — PASS — hardest: Embedding, Agentic alerts — tip: know verified questions cold, 3 scenarios on them
```
```
📋 RESULT: MC Next — FAIL (retaking) — hardest: consent objects, contact point priority — tip: the consent object model diagram is worth memorizing
```
Failed attempts are the most valuable posts in the channel — they steer next
week's research directly. No scores needed, no shame, ever.

**2. Hard topic** (post mid-study when something isn't clicking)
```
❓ HARD TOPIC: MC Next — can't keep segment-triggered vs. record-triggered flow scenarios straight
```

**3. Resource** (post when you find something that actually helped)
```
🔗 RESOURCE: <link> — best explanation of BU↔Data Space isolation I've found
```

## What happens automatically

Every **Monday ~7am** the pipeline bot:
1. Reads the week's channel posts
2. Checks both exam guides for changes and searches for new enablement
3. Digs deeper on anything flagged hard or failed
4. Posts a **weekly digest** here (congrats, what's new, targeted fixes, suggested focus)
5. Publishes a snapshot that updates the **Cert Prep Hub** — the shared study
   app — so its Insights tab, Research tab, and practice-quiz weighting reflect
   the team's real experience

## Ground rules
- Don't share actual exam questions — section names and topic areas only
  (certification agreement applies).
- First names or initials are fine; the digest credits tips by whatever you post.
- New joiner? Pin: the Cert Prep Hub link + this guide.
