# 📚 Cert Prep — How to Use This Channel

Everything you need to prep for **Tableau Next Consultant**, **Marketing Cloud Next Consultant**,
and **Data 360 Consultant** — study in Claude Code, track progress here.

---

## 1. Install the `cert-prep` skill (one time, ~2 min)

The skill runs in **Claude Code** (Code + Cowork only — never claude.ai, per CSG).

**You need two files** in a folder called `cert-prep`:
- `SKILL.md`
- `cert-plans.json`

**Option A — from the shared repo (preferred):**
1. Clone the `cert-prep-kit` repo from [ (paste repo link here) ].
2. Copy its `skills/cert-prep/` folder into your own `~/.claude/skills/` directory.
   (On Mac/Linux, from inside the repo: `cp -R skills/cert-prep ~/.claude/skills/`.)

**Option B — paste the files:**
1. Create the folder: `mkdir -p ~/.claude/skills/cert-prep`
2. Save the two files (posted below / attached) into it as `SKILL.md` and `cert-plans.json`.

**Then:** open (or restart) Claude Code so it picks up the new skill.

---

## 2. Use it

Just ask Code, naturally:
- **"Help me study for Data 360"** (or Tableau Next, or MC Next) → a product-aware 80/20 study
  plan weighted to the real exam.
- **"Quiz me on MC Next"** → scenario-based practice questions with explanations.
- **"What's new for the Tableau Next exam?"** → live web research on the newest enablement.
- **"Explain identity resolution for Data 360"** → topic tutoring.

It runs at full quality in Code — real reasoning, real web search, multi-turn.

---

## 3. Log your progress

Click the pinned **📊 Cert Prep progress** workflow *(coming soon)* whenever you finish a study
session, a practice round, or sit the exam. Quick form: exam, status, sections done, practice %,
hardest sections, a tip. That's how the team tracker stays current.

---

## 4. Talk shop

Post freely in the channel:
- **❓ HARD TOPIC** — when something isn't clicking
- **🔗 RESOURCE** — a link that helped
- **🎉 Result** — celebrate a pass, or share what a fail taught you

---

## Ground rules

- **Never share real exam questions** — topic areas only (cert agreement applies). The skill only
  generates original practice scenarios; don't paste live exam content anywhere.
- **Code only** — the Bedrock-hosted Claude Code, never claude.ai.
- Exam guides are Knowledge articles — if you want the skill to use one, **paste the text**; never
  upload screenshots or files.
